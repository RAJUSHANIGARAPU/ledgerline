# Contributing

Thanks for your interest. Ledgerline is licensed under AGPL-3.0-only, and its author also offers it
as a hosted service. To keep that possible, outside code contributions are not accepted at the moment.

You are welcome to:
- open an issue for a bug, with steps to reproduce;
- open an issue for a VAT or invoicing rule you believe is wrong, with a link to the
  belastingdienst.nl page that says so (see `src/ledgerline/vat/sources.py` for how rules are sourced).

Security problems: please do not open a public issue; see [docs/SECURITY.md](docs/SECURITY.md).
